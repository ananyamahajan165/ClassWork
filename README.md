# ClassWork

## 📖 Overview
This repository contains C programming lab assignments and practice programs created as part of academic coursework. The programs focus on building a strong foundation in C programming concepts and basic problem-solving techniques.

It also serves as practice for using Git and GitHub workflows such as forking, committing, and syncing repositories.

---

## 🧠 Topics Covered
- Basic C syntax and structure
- Loops and conditional statements
- Functions and recursion
- Number system conversions
- Mathematical algorithms
- Git and GitHub basics

---

| File / Folder        | Description |
